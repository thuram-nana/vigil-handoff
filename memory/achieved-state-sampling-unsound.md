VIGIL Lane S (GOLD-STANDARD Part 13, S1): the `ACHIEVED_STATE` arm (`verify/oracles.py` `predicate_oracle`) mints a FACT from a producer-authored JSON-AST predicate over `observed_evidence`. Two fix attempts were red-pen-BLOCKED:

1. **Syntactic reflexive-op detector** (`{"eq":["x","x"]}`) — missed threshold/type tautologies (`min_len<=0`, `in[var,var]`, `ge[var,""]`).
2. **Counterfactual perturbation gate** (perturb each captured var across sentinel families; refuse iff it fires under EVERY non-erroring perturbation) — BLOCKED as fundamentally unsound: **sampling over a fixed/public/finite probe set cannot decide value-independence.** The adversary crafts a predicate false at EXACTLY one probe value, true everywhere else over the real domain, e.g. `not(eq[{var:body},0])` (a captured HTTP body is a string, never int 0 → true for every real capture, adjudicates nothing) — the int-0 perturbation spuriously flips it → "value-dependent" → signed false FACT, `framework.v2 verify` exit 0, `verify_pcf` all 5 steps. Also `not(eq[body,"<the fix's own public sentinel>"])`, `min_len>=1`, `not(eq[body,""])`. Adding more families does NOT help — the adversary moves the flip-point.

**The sound rule (red-pen-prescribed, correct):** decide FACT-eligibility STRUCTURALLY, not by sampling. Either (1) a predicate GRAMMAR where firing is contingent on a RELATIONSHIP AMONG captured values — every discriminating leaf binds a captured var vs another captured var OR vs an out-of-band, independently-provenanced reference (a signed canary / server-chosen nonce the producer CANNOT author) — inline producer literals forbidden as sole discriminators (protocol-status constants + numeric floors allowed in dedicated positions); OR (2) demote the whole producer-authored-predicate arm to LEAD until that binding exists (the precedent: nuclei-substring M1.4, [[vigil-wave1-remaining-gaps-lessons]]).

**Why structure alone isn't fully sound either (TM-B):** over a FULLY producer-controlled context the producer also controls any canary/signature/discriminator literal, so NO oracle-local check is sound against a maximally-adversarial producer. Genuineness ultimately rests on the GATED SEAM having injected a real canary + captured real bytes + the two-env SIGNATURE. TM-B-complete soundness needs a spine-recorded INJECTION NONCE (pre-dating capture, append-only) the oracle/offline-verifier checks. The honest docstring split: the oracle proves the predicate HOLDS value-dependently over the RETAINED evidence; the seam-capture + signature + out-of-band trust-root pin are the PROVENANCE authority — do NOT call the oracle a "value-dependence authority".

Real predicate shapes (grounds the grammar): `web_redrive._build_liveness_predicate` (open_redirect) = pure captured-var-vs-captured-var sha/status equalities + HTTP-status anchors + count floors (soundly keepable). `access_control_redrive` (idor/bola) = a victim-UNIQUE discriminator present in BOTH attacker and victim substantive bodies, ABSENT from 4 controls (relationship-rich). `runtime_redrive._secret_value_predicates` = captured-var-vs-captured-var contains + inline-literal signature/denylist/min-len (literal-bearing → needs the references slot or honest LEAD).

**Why:** faking a FACT is the one forbidden outcome; an honest LEAD beats a false FACT ([[claim-discipline-meet-up]], [[runtime-redrive-live-false-fact]]). A soundness gate at the PREDICATE must be structural/provenance-bound, never statistical. **How to apply:** never decide a producer-authored predicate's soundness by sampling/perturbation; require a structural relationship among captured values + a provenance-bound reference; demote with named blocking_work if not yet built.
